# Immortalis Brain — website

Separate project. Not Gridiron Vision.

## Open the site

1. Unzip this folder.
2. Open `index.html` in Safari or Chrome.
3. Tap **Engage core** (phones block sound until you tap).

Needs WebGL and speech. Works offline after the first load if Three.js is cached; keep internet on for the 3D globe CDN.
